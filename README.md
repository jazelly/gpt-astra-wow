# Echoes of Elwynn

A playable, single-player, Warcraft-inspired 3D fantasy adventure for desktop browsers. Explore a handcrafted low-poly valley, complete a three-stage quest chain, upgrade your equipment, and defeat the Hollow King.

This is an independent fan game, not the commercial World of Warcraft client or an MMO. All world geometry, characters, props, visual effects, and sound effects are generated by this project; no Blizzard assets are included.

## Play

Requires Node.js 22.12+ or 24+ and a modern browser with WebGL 2 support.

```sh
npm install
npm run dev
```

Open the local address printed by Vite. Alternatively, double-click `Play.command` on macOS with Node.js installed. Choose a class and press **Enter the World**.

For a production build:

```sh
npm run build
npm run preview
```

## Controls

| Action                            | Input                                 |
| --------------------------------- | ------------------------------------- |
| Move                              | WASD, arrow keys, or click the ground |
| Approach and automatically attack | Click an enemy                        |
| Select nearby enemy               | Tab                                   |
| Basic attack                      | Hold Space or press 1                 |
| Area attack                       | 2                                     |
| Defensive ability                 | 3                                     |
| Healing ability                   | 4                                     |
| Healing potion                    | Q                                     |
| Speak to the marshal              | E, within 5 meters                    |
| Inventory                         | B                                     |
| Quest journal                     | J                                     |
| Expand minimap                    | M                                     |
| Pause / resume                    | Escape                                |
| Controls                          | H                                     |

Every ability can also be activated from the on-screen action bar. Manual movement cancels click-to-move and automatic attacks.

## Complete the adventure

1. Speak to Marshal Aldric beside the Northshire campfire and accept his quest.
2. Defeat three timber wolves in the western grove, then return to Aldric for a weapon upgrade.
3. Cross the river and defeat three Blackrock marauders in the eastern camp. Return for armor and potions.
4. Follow the road north to the Forgotten Gate. Defeat Mordrath, the Hollow King. Move out of the red circle before his ground slam, and use healing and defense abilities.
5. Return to Aldric to receive the Medallion of Northshire and the completion screen.

Warrior uses close-range strikes; Mage and Ranger can attack from a distance. Energy regenerates during play. Leveling restores health and energy. Quest equipment is equipped automatically. Aldric's camp restores health. Death returns you to camp through the revive button without losing quest progress or equipment.

Progress is kept for the current page session. Refreshing or choosing **New Adventure** starts a new run. There is no account, server, multiplayer, or persistent save system.

## Implementation

The game uses Three.js and Vite. Geometry is authored procedurally in `src/main.js`; the interface is in `index.html` and `src/style.css`. Combat and quests run locally in the browser. Cinzel and Inter are bundled locally under the SIL Open Font License; their licenses are included in `public/fonts`. No external asset requests are needed while playing. `window.gameStatus()` exposes a read-only snapshot for manual verification, without mutation or gameplay bypasses.

## Playthrough verification

Verified in the actual browser through keyboard and mouse input, without changing game state:

- Warrior: accepted quests, defeated three wolves and four marauders, claimed both equipment upgrades, defeated Mordrath, returned to Aldric, and reached the victory screen at level 5 with 256 gold.
- Death and revival: returned to camp with health restored and quest progress, equipment, gold, and potions retained.
- Mage: ranged kills and Frost Nova damage verified; the affected wolf stopped moving while an unaffected wolf continued approaching.
- Ranger: ranged attacks and Arrow Rain produced kills and XP rewards.
- Healing potions, healing skills, guard skills, inventory, quest journal, expanded map, pause, and post-victory exploration were exercised.
- The production build loaded successfully with locally bundled fonts and no external resource requests.
